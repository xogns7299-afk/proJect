# proJect — 공부 관리 웹앱

> 2026 SCNU OSS·AI 해커톤 (기초트랙) 출품작 · **현재 기획 단계**

혼자 하는 공부를 타이머로 기록하고, 캐릭터를 키우고, 스터디 멤버들의 공부하는 모습을 보며 자극받는 심플한 공부 관리 웹앱입니다.

## 주요 기능 (예정)

- **공부기록 타이머** — 과목을 골라 시작 → 일시정지/종료 → 공부 내용 작성 → 자동 기록. 과목별 공부시간 조회
- **To-do 리스트** — 단순 체크리스트
- **일정관리** — 개인 캘린더 + 스터디 모임 일정
- **주간 목표** — 이번 주 목표와 달성률, 스터디에 자동 공유
- **스터디 공유** — 멤버끼리 서로의 공부 기록·목표 달성 현황 보기
- **레벨업 시스템** — 캐릭터를 고르고, 공부하면 경험치를 얻어 레벨업

> 현재 저장소에는 빈 화면과 서버 상태 확인 API만 있는 최소 뼈대가 들어 있습니다. 기능은 기획이 확정된 뒤 구현합니다.

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프론트엔드 | HTML, CSS, JavaScript |
| 백엔드 | [Hono](https://hono.dev) (TypeScript) |
| 배포 | Cloudflare Pages (Genspark 호스팅) |
| 데이터 저장 (예정) | Cloudflare D1, R2 |
| 개발 도구 | Claude Code, Genspark CODE |

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install      # 최초 1회
npm run dev      # 개발 서버 실행 → http://localhost:5173
npm run build    # 배포용 빌드 → dist/
```

## 폴더 구조

```
├── src/index.tsx        # 서버 진입점 (Hono)
```
