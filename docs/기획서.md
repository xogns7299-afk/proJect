## 1. 한 줄 소개

혼자 하는 공부를 타이머로 기록하고, 캐릭터를 키우고, 스터디 멤버들의 공부하는 모습을 보며 자극받는 **심플한 공부 관리 웹앱**.

## 2. 방향 [확정]

- 심플하고 사용하기 쉬운 앱. 화면(UI)은 가볍게.
- 앱 내부 AI 기능은 넣지 않는다. 독립적인 관리 웹앱이다.
- 스터디 그룹의 취지: 모여서 무언가를 하는 공간이 아니라, **서로의 공부 기록과 목표 달성 모습을 보며 의욕·자극을 받는 공간**.
- 개인 페이지에서 한 활동이 스터디에 **자동으로 연동**된다. 스터디용으로 따로 입력하지 않는다.

## 3. 주요 기능 [확정]

| # | 기능 | 요약 |
|---|---|---|
| 1 | 공부기록 타이머 | 과목을 골라 시작 → 일시정지/종료 → 공부 내용 작성 → 자동 기록. 오공시·오공완 사진은 선택 |
| 2 | To-do 리스트 | 단순 체크리스트 (날짜·캘린더와 연결하지 않음) |
| 3 | 개인 일정관리 | 개인 캘린더 (본인만 봄) |
| 4 | 주간 목표 | 개인 페이지에서 이번 주 목표 작성 → 스터디에 자동 공유 |
| 5 | 스터디 | 멤버들의 공부 현황(이번 주 시간, 목표 달성, 지금 공부 중)과 공부 기록 피드 보기. 기록에 **응원(👏)·댓글** 남기기 |
| 6 | 레벨업 시스템 | 가입 시 캐릭터 선택. 공부하거나 목표를 완료하면 경험치 → 레벨업 |

## 4. 사용자 흐름

1. 회원가입 → 닉네임 입력, **캐릭터 선택**
2. 과목(공부 종류) 등록
3. 홈에서 "공부 시작" → 과목 선택 → (선택) 오공시 사진 → 타이머 시작
4. 일시정지/재개 → 종료 → 공부 내용 작성, (선택) 오공완 사진 → 저장
5. 경험치 획득, 레벨업 시 캐릭터 변화
6. 스터디에 가입해 있으면 방금 기록이 스터디 피드에 자동으로 보임
7. 이번 주 목표 작성·체크, To-do 체크, 일정 확인
