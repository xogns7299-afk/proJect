# 기능명세

- 최종 수정: 2026-09-26
- 표기: **[확정]** / **[제안]** / **[미정]**. 표기가 없는 세부 동작은 확정 내용을 구현하기 위한 기본 동작이다.
- 시간 기준: 한국시간(KST). 한 주는 월요일 시작.

## 0. 계정

- 회원가입: 아이디(또는 이메일)·비밀번호·닉네임 입력 → **캐릭터 선택** [확정] → 가입 완료.
- 로그인 상태는 새로고침·재접속 후에도 유지된다.
- 아이디는 영문 소문자·숫자·밑줄 4~20자, 비밀번호는 8자 이상. 비밀번호는 암호화(해시)해서 저장한다.

## 1. 공부기록 타이머 [확정]

### 1-1. 과목 관리
- 과목(공부 종류)을 미리 등록·수정·삭제한다. 예: 수학, 영어, 전공.
- 기록이 있는 과목을 삭제하면 목록에서만 숨기고 과거 기록은 유지한다.

### 1-2. 타이머 흐름

| 단계 | 화면 | 버튼 |
|---|---|---|
| 대기 | "공부 시작" 버튼 | 공부 시작 |
| 준비 | 캐릭터와 말풍선 + 내 과목 리스트(＋ 과목 추가) + **오늘의 공부 내용(선택 입력)** [확정 9/26] + 8시간 상한 안내 | 뒤로 · 타이머 시작 (과목을 골라야 활성화) |
| 진행 중 | 상태 배지(공부 중), **공부시간**(큰 숫자), 총 경과·휴식(참고), 과목·오늘의 공부 내용·시작 시각 | 일시정지 · 공부 종료(**한 번 더 확인**, 1분 미만이면 기록되지 않는다고 안내) · 타이머 켜 둔 채 나가기 |
| 일시정지 | 상태 배지(쉬는 중), 공부시간은 멈추고 휴식이 늘어남 | 공부 재개 · 공부 종료 |
| 회고 | 시간 요약(과목·시작·종료·총 경과·휴식 n회·공부시간) + 회고 4칸 | 나중에 쓰기 · 회고 저장 |
| 완료 | 이번 기록·오늘 누적·획득 경험치, 경험치 바, 레벨업 시 연출 | 홈으로 |

- 화면 구성은 팀원 2의 타이머 인터페이스 명세를 따른다. 홈에서 **집중 모드(화면 전체)**로 열리고, PC에서는 왼쪽·오른쪽 2단으로 배치한다. [9/26]
- 집중 모드는 Esc·브라우저 뒤로가기로 닫힌다. 닫아도 타이머는 서버에서 계속 돌아간다. 타이머가 도는 동안 **브라우저 탭 제목**(`⏱ 00:45:19 수학 · proJect`)과 **왼쪽 메뉴**에 시간이 보인다. [9/26]
- 타이머가 돌아가는 동안 홈의 "공부 시작" 버튼은 "○○ 공부 중 · 시간"으로 바뀐다.

### 1-3. 규칙
- **일시정지한 시간은 공부시간에서 제외한다.** [확정]
  공부시간 = (종료 시각 − 시작 시각) − 일시정지 합계
- **타이머는 서버에 저장된 시작 시각 기준으로 계산한다.** [확정] 새로고침하거나 브라우저를 닫았다 열어도 이어진다.
- **한 번에 하나의 타이머만** 실행할 수 있다. [확정]
- 종료 버튼을 여러 번 눌러도 기록은 하나만 생긴다.
- 공부 내용은 비워 두고 저장할 수 있다.
- 기록은 **시작한 날짜·주차**에 합산한다. (자정을 넘겨도 시작일 기준)
- 1분 미만 기록은 저장하지 않고, 종료할 때 그 사실을 알려준다. [제안]
- **한 번의 기록은 최대 8시간.** [확정] 8시간을 채우면 자동으로 종료되고 8시간만 기록된다. 준비 화면에서 "한 번에 최대 8시간까지 기록돼요. 더 공부할 때는 한 번 끊고 점검한 뒤 다시 타이머를 켜 주세요"라고 미리 안내한다. 일시정지에는 상한을 두지 않는다(일시정지 중에는 공부시간이 멈춰 있을 뿐 줄지 않는다). 공부시간이 8시간을 넘긴 채 일시정지돼 있어도 다음 요청 때 자동 종료된다. 자동 종료 결과는 어느 화면으로 들어오든 회고 화면으로 안내한다. [9/26]
- **회고는 4칸**(오늘 공부한 내용 / 성과 / 어려웠던 점 / 비고), 전부 선택 입력. [확정 — 9/26 팀원 1 사양서의 3칸안 대신 4칸 유지 재확인] 준비 화면에서 적은 "오늘의 공부 내용"이 있으면 회고의 "오늘 공부한 내용" 칸에 미리 채워지고 고칠 수 있다. [확정 9/26] (같은 칸에 저장되므로 회고를 건너뛰어도 스터디 피드에 보인다) 스터디 피드에는 "오늘 공부한 내용"만 보이고 나머지는 본인만 본다. "나중에 쓰기"로 건너뛰면 기록 탭에서 이어 쓸 수 있다.
- 저장한 기록은 내용 수정·삭제가 가능하다. 삭제하면 합계와 해당 경험치도 함께 되돌린다.

### 1-4. 오공시·오공완 사진 [확정: 선택 사항]
- 시작할 때 오공시 사진, 종료할 때 오공완 사진을 첨부할 수 있다. 첨부하지 않아도 된다.
- 사진은 업로드 전에 브라우저에서 축소한다(긴 변 1280px). [제안 — 저장 용량 절약]
- 업로드에 실패해도 타이머·입력 내용은 유지되고 다시 시도할 수 있다.

### 1-5. 조회
- 오늘 / 이번 주 / 전체 누적 공부시간.
- **과목별** 공부시간 합계와 기록 목록(날짜, 시간, 내용, 사진). [확정]

## 2. To-do 리스트 [확정: 단순 체크리스트]

- 화면 구성은 팀원 2의 할 일 목록 명세를 따른다.
- 항목 추가(80자), 완료 체크/해제, 삭제. 저장 버튼 없이 바로 반영된다.
- 최신순으로 보여주고, **전체 / 진행중 / 완료** 필터로 거른다(각 개수 표시). 필터별로 빈 상태 문구가 다르다.
- 날짜·캘린더와 연결하지 않는다. 공부 종류 태그도 두지 않는다. [확정] 본인만 본다.
- "완료 항목 지우기"로 한 번에 정리한다.
- 홈 화면에는 진행중·완료 개수 요약을 보여준다.

## 3. 개인 일정관리

- 월간 캘린더. 날짜를 눌러 일정 추가(제목, 날짜, 시간(선택), 메모(선택)), 수정, 삭제.
- PC에서는 달력 칸 안에 일정 제목을 2개까지 보여주고 나머지는 "+n개". 좁은 창에서는 점으로 표시. 일요일 빨강·토요일 파랑. [9/26]
- 종료 시각이 시작 시각보다 빠르면 저장하지 않는다(서버에서도 거부). [9/26]
- 본인만 본다. 스터디와 연결하지 않는다. [확정]
- 이전 달·다음 달 이동, 일정이 있는 날짜에 점 표시, 날짜를 누르면 그날 일정 목록.

## 4. 스터디

### 4-1. 생성·가입
- 누구나 스터디를 만들 수 있고, 만든 사람이 스터디장이 된다.
- 한 사람이 여러 스터디에 동시에 가입할 수 있다. [확정]
- 가입은 **초대 코드** 입력으로 한다. [제안]
- 탈퇴할 수 있다. 탈퇴하면 그 스터디 피드에서 내 기록이 보이지 않는다(내 개인 기록은 그대로).

### 4-2. 스터디 화면 [확정]
화면 순서: ① 내 스터디 선택(칩) + 가입/만들기 → ② 멤버 현황 → ③ 공부 기록 피드 → ④ 스터디 정보(초대 코드 복사, 나가기/삭제)

- 모임 일정 기능은 두지 않는다. [확정]
- 멤버 현황: 이번 주 공부시간이 많은 순. 캐릭터·레벨, 이번 주 공부시간, 목표 달성(막대 + n/m), 지금 공부 중이면 "○○ 공부 중" 표시. 멤버를 누르면 그 사람의 이번 주 목표가 펼쳐진다.
- 멤버들의 최근 공부 기록: 닉네임, 캐릭터·레벨, 과목, 공부시간, 내용, 사진.
- 개인 페이지의 기록이 자동으로 나타난다. 스터디용으로 따로 입력하지 않는다.

### 4-3. 응원·댓글 [확정]
- 피드의 공부 기록마다 **응원(👏)** 을 누를 수 있다. 다시 누르면 취소. 자기 기록은 응원할 수 없다.
- 기록마다 **댓글**을 달 수 있다(300자). 댓글은 쓴 사람만 지울 수 있다.
- 응원·댓글은 **그 스터디 안에서만** 보인다. 같은 기록이 다른 스터디에도 공유되어 있어도, 서로 모르는 다른 스터디 사람의 반응이 섞여 보이지 않는다.
- 기록이 삭제되거나 스터디가 삭제되면 응원·댓글도 함께 사라진다.

## 5. 주간 목표 [확정: 개인 페이지에서 작성 → 스터디 자동 연동]

- 개인 페이지에서 **이번 주 목표**를 작성한다.
- 형식: 목표 항목 체크리스트. 달성률 = 완료 항목 수 ÷ 전체 항목 수. [제안 — 레벨업의 "목표 완료 시 경험치"와 자연스럽게 연결됨]
- 월요일이 되면 새 주차가 시작되고, 지난 주차는 보관되어 다시 볼 수 있다. 홈의 목표 카드에서 ‹ › 로 주를 옮긴다. **지난 주 목표는 보기만** 가능하다(추가·체크·삭제는 서버에서도 거부) — 끝난 주의 경험치가 바뀌지 않게 하기 위해서다. [확정 9/26]
- 목표를 체크하면 "+30 XP 목표 달성!", 그로 인해 레벨이 오르면 "레벨 업! Lv.n" 알림이 잠깐 뜬다. [9/26]

## 6. 홈 화면

- **웹앱 · PC 브라우저 기준** [확정 9/26]. 모바일 앱이 아니다. 좁은 창(860px 이하, 휴대폰 브라우저)은 반응형으로 대응한다.
- 화면 구조 [확정 9/26]:
  - PC: **왼쪽 메뉴**(로고 / 홈·공부 기록·할 일·캘린더·스터디 / 진행 중 타이머 / 맨 아래 내 캐릭터·닉네임·레벨 → 내 정보, 다크 모드 버튼) + 넓은 본문(최대 1160px)을 2단으로.
  - 좁은 창: 한 줄로 쌓고 메뉴는 하단 탭 5개, 상단에 다크 모드·내 정보 버튼.
  - 입력 창은 화면 가운데 대화상자. Esc·바깥 클릭·브라우저 뒤로가기로 닫힌다.
  - 브라우저 탭 제목은 화면 이름(`홈 · proJect`), 타이머가 돌면 시간.
- 홈: 왼쪽 = 캐릭터 카드(레벨에 맞는 전신 그림·닉네임·레벨·경험치 바) → 오늘 누적·이번 주·전체 → "공부 시작"(진행 중이면 그 타이머) → 최근 기록 4건 / 오른쪽 = 주간 목표(작성·체크, ‹ › 주 이동) → 진행중 할 일 5개(체크하면 완료). 좁은 창에서는 목표·할 일이 최근 기록보다 위.
- 불러오는 동안 홈은 카드 모양의 회색 틀을 먼저 보여준다.
- 기록: 왼쪽 = 과목별 공부시간, 과목 관리(추가·이름 수정·삭제) / 오른쪽 = 전체 기록(과목 필터, 누르면 회고 이어 쓰기·사진·삭제)
- 캘린더: 왼쪽 = 큰 달력 / 오른쪽 = 고른 날의 일정. 스터디: 왼쪽 = 멤버 현황·스터디 정보 / 오른쪽 = 공부 기록 피드. 할 일: 한 단(최대 720px).
- 내 정보(대화상자): 닉네임·캐릭터 바꾸기(레벨·경험치는 그대로), 로그아웃. [확정 9/26]

## 7. 레벨업 시스템 [확정]

### 7-1. 캐릭터
- 가입할 때 캐릭터를 하나 고른다. [확정]
- 레벨 구간에 따라 캐릭터 모습이 바뀐다: Lv1~4 / 5~9 / 10+. [확정 9/26 — 팀원 1 사양서의 Lv5·Lv10 변화 기준] 성장 단계 그림은 현재 리트리버만 있고, 나머지 캐릭터는 모습이 고정이다.
- 그림: 팀원 1 캐릭터 4종(리트리버·삼색냥이·검정냥이·달마시안) 적용. [확정 9/26]

- 캐릭터 애니메이션(대기·걷기·반응·타이머 프레임·레벨업 연출)은 그림이 모이면 목업으로 먼저 확인한 뒤 붙인다. [미정 — 그림 대기]

### 7-2. 경험치 [확정 9/26]

> 팀원 1 사양서(9/24)의 "10분 = 1 XP, 남는 시간 이월"안은 채택하지 않고 아래 현재 값을 유지한다.

| 행동 | 경험치 | 비고 |
|---|---|---|
| 공부 | 1분당 1 XP | 기록 1건당 최대 240 XP (타이머를 켜 둔 채 방치하는 경우 방지) |
| 주간 목표 항목 완료 | 항목당 30 XP | 체크를 해제하면 회수. **이번 주 목표만, 한 주에 10개까지** [확정 9/26 — 목표만 잔뜩 만들어 레벨을 올리지 못하게]. 11번째부터는 체크는 되지만 경험치는 없다 |
| To-do 완료 | 없음 | 남용하기 쉬워 제외. 넣고 싶다면 항목당 5 XP, 하루 최대 50 XP |

- 같은 기록·항목으로 경험치가 두 번 지급되지 않는다.

### 7-3. 레벨 [확정 9/26]

> 팀원 1 사양서(9/24) 레벨표(Lv2=30 … Lv10=630 XP)는 채택하지 않고 아래 현재 값을 유지한다.

- 레벨 N → N+1에 필요한 경험치: 100 × N.
- 누적 기준: Lv2 = 100, Lv3 = 300, Lv4 = 600, Lv5 = 1000, Lv10 = 4500.
- 예: 10시간 공부(600 XP) → Lv4. 초반에 빨리 오르고 갈수록 천천히 오른다.
