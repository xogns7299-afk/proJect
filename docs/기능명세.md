# 기능명세

- 최종 수정: 2026-09-21
- 표기: **[확정]** / **[제안]** / **[미정]**. 표기가 없는 세부 동작은 확정 내용을 구현하기 위한 기본 동작이다.
- 시간 기준: 한국시간(KST). 한 주는 월요일 시작.

## 0. 계정

- 회원가입: 아이디(또는 이메일)·비밀번호·닉네임 입력 → **캐릭터 선택** [확정] → 가입 완료.
- 로그인 상태는 새로고침·재접속 후에도 유지된다.
- 구현 방식은 서버 저장 방식 결정에 따른다. [미정]

## 1. 공부기록 타이머 [확정]

### 1-1. 과목 관리
- 과목(공부 종류)을 미리 등록·수정·삭제한다. 예: 수학, 영어, 전공.
- 기록이 있는 과목을 삭제하면 목록에서만 숨기고 과거 기록은 유지한다.

### 1-2. 타이머 흐름

| 단계 | 화면 | 버튼 |
|---|---|---|
| 대기 | "공부 시작" 버튼 | 공부 시작 |
| 준비 | 타이머(00:00:00) + 내 과목 리스트 + (선택) 오공시 사진 첨부 | 시작 (과목을 골라야 활성화) |
| 진행 중 | 돌아가는 타이머 + 선택한 과목 | 일시정지 · 종료 |
| 일시정지 | 멈춘 타이머 | 계속 · 종료 |
| 종료 입력 | "오늘 무엇을 공부했나요?" 입력 칸 + (선택) 오공완 사진 첨부 | 저장 |
| 저장 완료 | 공부시간·획득 경험치 표시, 레벨업 시 연출 | 확인 |

### 1-3. 규칙
- **일시정지한 시간은 공부시간에서 제외한다.** [확정]
  공부시간 = (종료 시각 − 시작 시각) − 일시정지 합계
- **타이머는 서버에 저장된 시작 시각 기준으로 계산한다.** [확정] 새로고침하거나 브라우저를 닫았다 열어도 이어진다.
- **한 번에 하나의 타이머만** 실행할 수 있다. [확정]
- 종료 버튼을 여러 번 눌러도 기록은 하나만 생긴다.
- 공부 내용은 비워 두고 저장할 수 있다.
- 기록은 **시작한 날짜·주차**에 합산한다. (자정을 넘겨도 시작일 기준)
- 1분 미만 기록은 저장하지 않는다. [제안]
- 저장한 기록은 내용 수정·삭제가 가능하다. 삭제하면 합계와 해당 경험치도 함께 되돌린다.

### 1-4. 오공시·오공완 사진 [확정: 선택 사항]
- 시작할 때 오공시 사진, 종료할 때 오공완 사진을 첨부할 수 있다. 첨부하지 않아도 된다.
- 사진은 업로드 전에 브라우저에서 축소한다(긴 변 1280px). [제안 — 저장 용량 절약]
- 업로드에 실패해도 타이머·입력 내용은 유지되고 다시 시도할 수 있다.

### 1-5. 조회
- 오늘 / 이번 주 / 전체 누적 공부시간.
- **과목별** 공부시간 합계와 기록 목록(날짜, 시간, 내용, 사진). [확정]

## 2. To-do 리스트 [확정: 단순 체크리스트]

- 항목 추가, 완료 체크/해제, 삭제.
- 날짜·캘린더와 연결하지 않는다. 본인만 본다.
- 완료한 항목은 아래로 내려가고, "완료 항목 지우기"로 한 번에 정리한다. [제안]

## 3. 개인 일정관리

- 월간 캘린더. 날짜를 눌러 일정 추가(제목, 날짜, 시간(선택), 메모(선택)), 수정, 삭제.
- 본인만 본다.
- 내가 가입한 스터디의 **모임 일정이 함께 표시**된다. [확정] 색으로 구분하고, 개인 캘린더에서는 수정할 수 없다(읽기 전용).

## 4. 스터디

### 4-1. 생성·가입
- 누구나 스터디를 만들 수 있고, 만든 사람이 스터디장이 된다.
- 한 사람이 여러 스터디에 동시에 가입할 수 있다. [확정]
- 가입은 **초대 코드** 입력으로 한다. [제안]
- 탈퇴할 수 있다. 탈퇴하면 그 스터디 피드에서 내 기록이 보이지 않는다(내 개인 기록은 그대로).

### 4-2. 스터디 일정관리 [확정]
- 스터디장이 모임 일정을 등록·수정·삭제한다(제목, 날짜, 시간, 장소(선택), 메모(선택)).
- 등록한 일정은 모든 멤버의 개인 캘린더에 자동 표시된다. 수정·삭제도 바로 반영된다(복사본을 만들지 않고 원본을 같이 조회).

### 4-3. 스터디 피드 [확정]
- 멤버들의 최근 공부 기록: 닉네임, 캐릭터·레벨, 과목, 공부시간, 내용, 사진.
- 멤버별 이번 주 공부시간, 이번 주 목표와 달성률.
- 지금 공부 중인 멤버 표시. [제안 — 자극 효과가 크고 구현이 쉬움]
- 개인 페이지의 기록이 자동으로 나타난다. 스터디용으로 따로 입력하지 않는다.

## 5. 주간 목표 [확정: 개인 페이지에서 작성 → 스터디 자동 연동]

- 개인 페이지에서 **이번 주 목표**를 작성한다.
- 형식: 목표 항목 체크리스트. 달성률 = 완료 항목 수 ÷ 전체 항목 수. [제안 — 레벨업의 "목표 완료 시 경험치"와 자연스럽게 연결됨]
- 월요일이 되면 새 주차가 시작되고, 지난 주차는 보관되어 다시 볼 수 있다.

## 6. 홈 화면

- 내 캐릭터·레벨·경험치 바
- "공부 시작" 버튼 (진행 중인 타이머가 있으면 그 타이머)
- 오늘 공부시간, 이번 주 목표 달성률
- To-do 요약, 오늘 일정

## 7. 레벨업 시스템 [확정: 도입 / 세부 수치는 제안]

### 7-1. 캐릭터
- 가입할 때 캐릭터를 하나 고른다. [확정]
- 레벨 구간에 따라 캐릭터 모습이 바뀐다(예: 1~4 / 5~9 / 10~19 / 20+). [제안]
- 그림: 우선 이모지·간단한 그림으로 만들고, 팀이 그림을 준비하면 교체한다. [미정]

### 7-2. 경험치 [제안]

| 행동 | 경험치 | 비고 |
|---|---|---|
| 공부 | 1분당 1 XP | 기록 1건당 최대 240 XP (타이머를 켜 둔 채 방치하는 경우 방지) |
| 주간 목표 항목 완료 | 항목당 30 XP | 체크를 해제하면 회수 |
| To-do 완료 | 없음 | 남용하기 쉬워 제외. 넣고 싶다면 항목당 5 XP, 하루 최대 50 XP |

- 같은 기록·항목으로 경험치가 두 번 지급되지 않는다.

### 7-3. 레벨 [제안]
- 레벨 N → N+1에 필요한 경험치: 100 × N.
- 누적 기준: Lv2 = 100, Lv3 = 300, Lv4 = 600, Lv5 = 1000, Lv10 = 4500.
- 예: 10시간 공부(600 XP) → Lv4. 초반에 빨리 오르고 갈수록 천천히 오른다.

## 8. 검증 시나리오 (구현 후 확인할 것)

| 상황 | 기대 결과 |
|---|---|
| 타이머 진행 중 새로고침·브라우저 재실행 | 같은 타이머가 이어짐 |
| 일시정지 5분 포함 30분 경과 후 종료 | 공부시간 25분 |
| 종료·저장 버튼 중복 클릭 | 기록 1건, 경험치 1회 |
| 계정 A·B 같은 스터디, C 다른 스터디 | A의 기록이 B에게만 보이고 C에게는 안 보임 |
| A가 스터디 2곳 가입 | 두 스터디 피드에 모두 보이고, 개인 누적은 중복되지 않음 |
| 스터디장이 모임 일정 등록·수정·삭제 | 멤버 개인 캘린더에 바로 반영 |
| 기록 삭제 | 개인 합계·스터디 피드·경험치가 함께 변경 |
| 자정·월요일 경계를 넘는 기록 | 시작일·시작 주차에 합산 |
| 사진 업로드 실패 | 안내 후 입력 유지, 재시도 가능 |
| 다른 사람의 To-do·개인 일정 주소 직접 접근 | 서버에서 거부 |
