# 기술 스택 결정

- 결정일: 2026-09-21
- 결정: **A안 — Genspark 배포 방식에 맞춘 스택**

## 배경

배포는 대회 제공 Genspark로 진행한다. Genspark AI Developer의 배포 대상은 Hono(Node.js/TypeScript) + Cloudflare Pages이며 파이썬 서버(Flask 등)는 호스팅되지 않는 것으로 조사되었다. 마감(9. 27. 22:00)까지 기간이 짧고 본행사에서 배포 링크로 실구동 검증을 하므로, 배포 실패 위험이 가장 낮은 방식을 택했다.

## 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 프론트엔드 | HTML + CSS + JavaScript (빌드 없는 순수 JS) | `public/static/`에 둔다. 필요 시 CDN 라이브러리(Tailwind 등)만 사용 |
| 백엔드 | Hono (TypeScript) | `src/index.tsx`. 페이지 서빙 + `/api/*` 엔드포인트 |
| 배포 | Cloudflare Pages (Genspark 원클릭 배포) | Genspark가 GitHub 저장소를 가져와 배포 |
| AI 호출 | 백엔드 `/api/*`에서만 호출 | API 키는 환경변수(로컬 `.dev.vars`, 배포 시 시크릿). 브라우저에 노출 금지 |
| 데이터 저장 | Cloudflare D1 (SQLite) | 스키마는 `migrations/`. KV는 Genspark 호스팅에서 쓸 수 없다 |
| 로그인 | 직접 구현 | 비밀번호 PBKDF2-SHA256 해시 + 세션 토큰(쿠키, DB에는 해시만 저장). `src/lib/auth.ts` |

| 항목 | 답변 |

## 서버 저장 방식 (1안으로 뼈대 구현 — 2026-09-21)

이 앱은 계정·스터디·공부 기록·인증 사진을 서버에 저장해야 한다. 위 답변으로 Genspark 호스팅에서 D1·R2를 쓸 수 있는 것이 확인되어 추천을 바꾼다.

| 안 | 구성 | 장점 | 단점 |
|---|---|---|---|
| **1안 (추천) D1 + 직접 로그인 + R2, Genspark 호스팅(A)** | DB는 D1, 로그인은 직접 구현, 사진은 R2 | 추가 계정·외부 키가 필요 없음. 코드·DB 스키마가 저장소 하나에 모여 Genspark가 마무리하기 쉬움. 로컬에서 계정 없이 D1·R2를 흉내 내어 테스트 가능 | 로그인을 직접 구현해야 함(검증된 방식으로 신중히). R2 무료 한도 미확인 |
| 2안 Supabase | 로그인·DB·사진을 외부 Supabase로 | 로그인을 직접 만들지 않아도 됨 | 외부 계정·키 관리 필요. Genspark가 마무리할 때 다루기 어려움 |

- 사진(R2)이 시험 배포에서 막히면: 사진을 작게 줄여 D1에 저장하는 방식으로 대체하거나, 사진 기능의 우선순위를 낮춘다.
- 권한은 모든 API에서 서버가 검사한다 (화면에서 숨기는 것으로 끝내지 않음).
- 세션 서명용 비밀값은 시크릿으로만 둔다. 저장소·노션에 적지 않는다.

## 로컬 실행 방법

저장소 루트에서 실행한다. 뼈대는 `create-hono`의 `cloudflare-pages` 템플릿(Genspark와 같은 구조)으로 만들었다.

```bash
npm install               # 최초 1회
npm run db:migrate:local  # 로컬 DB 만들기 (최초 1회, 스키마가 바뀔 때마다)
npm run dev               # 개발 서버 (http://localhost:5173)
npm run check:api         # 개발 서버를 켠 채로: 다중 계정 검증 시나리오 자동 점검
npm run typecheck         # 타입 검사
npm run build             # 배포용 빌드 (dist/)
npm run db:reset:local    # 로컬 DB 비우고 다시 만들기
```

## 제약 (Cloudflare Workers 런타임)

- Node.js 전용 API(`fs`, `child_process` 등)와 파일 시스템 쓰기를 쓸 수 없다.
- 요청당 CPU 시간이 짧다 → 무거운 연산은 외부 AI API에 맡긴다.
- 상태는 서버 메모리에 보관할 수 없다 → 브라우저(localStorage) 또는 D1/KV.
