# 데이터 모델

- 최종 수정: 2026-09-21
- 실제 스키마는 `migrations/0001_init.sql` (Cloudflare D1). 이 문서는 그 설명이다.
- 문서에 없는 구현용 표: `auth_sessions`(로그인 세션. 토큰의 해시만 저장). `study_sessions`에는 집계용 `start_date`(시작 시각의 한국시간 날짜) 칸이 있다.
- 원칙: **원본은 하나만 두고 여러 화면에서 조회한다.** 스터디 피드·개인 캘린더용 복사본을 만들지 않는다.

## 표 목록

### users — 사용자
| 컬럼 | 설명 |
|---|---|
| id | |
| login_id / password | 로그인 정보 (저장 방식에 따라 인증 서비스가 대신 관리) |
| nickname | 스터디에 표시되는 이름 |
| character_id | 가입 시 고른 캐릭터 |
| created_at | |

### subjects — 과목
| 컬럼 | 설명 |
|---|---|
| id, user_id | |
| name | 예: 수학 |
| color | 표시 색 |
| archived | 삭제 시 true (과거 기록 유지용) |

### study_sessions — 공부 기록 (타이머 1회 = 1건)
| 컬럼 | 설명 |
|---|---|
| id, user_id, subject_id | |
| status | running / paused / done |
| started_at | 시작 시각 |
| paused_at | 일시정지 중일 때만 값이 있음 |
| paused_total_sec | 일시정지(휴식) 누적 초 |
| pause_count | 일시정지 횟수 |
| ended_at | 종료 시각 |
| duration_sec | 종료 시 확정: (ended_at − started_at) − paused_total_sec. 최대 8시간(28800초) — 넘으면 8시간으로 자르고 ended_at도 8시간을 채운 순간으로 맞춘다 |
| memo | 회고 1: 오늘 공부한 내용 (스터디 피드에 보이는 유일한 칸) |
| review_good, review_hard, review_note | 회고 2~4: 성과 / 어려웠던 점 / 비고 (본인만 봄) |
| start_photo, end_photo | 오공시·오공완 사진 (선택) |

- 한 사용자에게 status가 running/paused인 기록은 **최대 1건**.
- 진행 중 경과 시간 = 현재 시각 − started_at − paused_total_sec (일시정지 중이면 paused_at 기준). 서버 시각을 쓰므로 새로고침에 영향받지 않는다.
- 날짜·주차 집계는 started_at의 한국시간 날짜 기준.

| 컬럼 | 설명 |
|---|---|
| study_id, session_id, user_id | 세 값의 조합은 한 번만 (한 사람이 한 스터디에서 한 기록에 응원 1개) |
| created_at | |

### record_comments — 댓글
| 컬럼 | 설명 |
|---|---|
| id, study_id, session_id, user_id, body, created_at | |

- 응원·댓글에 `study_id`가 있는 이유: 기록은 주인이 가입한 모든 스터디에 보이지만, 반응은 남긴 스터디 안에서만 보이게 하기 위해서다.
- 기록(study_sessions)이나 스터디가 삭제되면 함께 삭제된다.

### xp_events — 경험치 내역
| 컬럼 | 설명 |
|---|---|
| id, user_id | |
| type | study_session / weekly_goal |
| ref_id | 근거가 된 기록·항목의 id |
| amount | |
| created_at | |

- (type, ref_id)는 한 번만 → 중복 지급 방지.
- 총 경험치 = amount 합계, 레벨은 총 경험치에서 계산한다(따로 저장하지 않음). 기록을 삭제하면 해당 내역도 삭제되어 자동으로 되돌려진다.

## 조회 규칙

| 화면 | 조회 방법 |
|---|---|
| 개인 누적·과목별 시간 | 내 study_sessions(done) 집계 |
| 스터디 피드 | 그 스터디 멤버들의 study_sessions·weekly_goal_items 조회 (복사 없음 → 여러 스터디에 가입해도 개인 누적이 중복되지 않음) |
| 개인 캘린더 | 내 events |

## 접근 권한 (서버에서 검사)

| 자료 | 읽기 | 쓰기 |
|---|---|---|
| todos, events, subjects | 본인 | 본인 |
| study_sessions, weekly_goal_items, xp 합계 | 본인 + 같은 스터디 멤버 | 본인 |
| users의 닉네임·캐릭터 | 본인 + 같은 스터디 멤버 | 본인 |
| studies, study_members | 그 스터디 멤버 | 가입·탈퇴는 본인, 스터디 수정은 스터디장 |
| record_cheers, record_comments | 그 스터디 멤버 | 그 스터디 멤버 (삭제는 본인 것만, 자기 기록 응원 불가) |
| 사진 파일 | 기록을 볼 수 있는 사람 | 본인 |
