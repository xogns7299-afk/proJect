## 2. 기술 구성

- 스택: HTML/CSS/JS(빌드 없는 순수 JS) + **Hono(TypeScript)** + **Cloudflare Pages**, DB **D1**, 사진 **R2**. 로그인은 직접 구현(PBKDF2 해시 + DB 세션 쿠키).
- Genspark 호스팅 제약(Genspark 답변): D1·R2만 지원, `wrangler.jsonc`에 **`kv_namespaces`·`triggers` 넣으면 배포 실패**, 앱 코드는 저장소 루트, GitHub 저장소 가져오기 가능. 권장 버전(Wrangler 3/Vite 5)보다 현재가 높음(Wrangler 4/Vite 8) → 배포에서 문제 날 수 있음.
- 폴더:
  ```
  src/index.tsx            진입점 (API 연결, 로그인 검사)
  src/renderer.tsx         HTML 틀 (제목 proJect, 아이콘, 서체, 테마 부트)
  src/lib/                 auth · xp · rules(조정 수치) · time(KST·주차) · app(공통)
  src/routes/              auth · subjects · timer · records · photos · todos · events · goals · studies
  migrations/0001_init.sql DB 스키마 (배포 전이라 이 파일을 직접 고치고 로컬 DB를 리셋한다)
  public/static/style.css  색 변수(라이트/다크) + 모든 스타일
  public/static/js/        app.js(탭 라우팅) · api.js · characters.js · photo.js · ui.js · dom.js · theme.js · views/{auth,home,timer,records,todo,calendar,study}.js
  public/static/img/       logo.png, favicon.png, icon-192/512.png, characters/*.png
  scripts/api-check.mjs    다중 계정 자동 검증 (55항목)
  docs/  mockup/(비어 있음, 초안은 .gitignore로 제외)  assets/
  ```
- 명령 (저장소 루트에서):
  ```bash
  npm install               # 최초 1회
  npm run db:migrate:local  # 로컬 DB 만들기 (최초 1회)
  npm run dev               # http://localhost:5173
  npm run check:api         # 개발 서버 켠 채로 실행 → 55항목 검증
  npm run typecheck / npm run build
  npm run db:reset:local    # 스키마 바꿨을 때 (개발 서버 끄고 실행)
  ```
- 로컬 DB에 데모 계정·스터디가 있을 수 있음(로컬 전용, 새 PC에는 없음). 화면 확인용 데이터는 `scripts/api-check.mjs`처럼 API로 넣으면 된다.

## 3. 확정된 제품 규칙

| 항목 | 확정 내용 |
|---|---|
| 화면 구조 | 하단 탭 5개: 홈 / 기록 / 할 일 / 캘린더 / 스터디. 타이머는 홈에서 전체 화면으로 |
| 타이머 | 과목 선택 → 시작 → 일시정지/재개 → 종료 → 회고. 일시정지 시간은 공부시간에서 제외. 서버 시작 시각 기준(새로고침·재접속해도 유지). 동시에 1개. 1분 미만 기록 안 함 |
| 8시간 상한 | 기록 1건 최대 8시간. 넘으면 자동 종료 + "한 번 끊고 점검 후 다시 켜기" 안내. 일시정지에는 상한 없음 |
| 회고 | 4칸(오늘 공부한 내용 / 성과 / 어려웠던 점 / 비고), 전부 선택. **"공부한 내용"만 스터디에 공유** |
| 사진 | 오공시(진행 화면)·오공완(회고) 선택 첨부. R2 저장. 기록 주인 + 같은 스터디 멤버만 열람 |

## 4. 아직 결정 안 된 것 (팀장에게 물을 것)

팀원 1의 `오공시_타이머_전체_기획_및_캐릭터성장_사양서.md`(9/24)가 현재 구현과 다른 부분:
1. **경험치:** 사양서 10분=1XP(남는 분 이월) vs 현재 1분=1XP. 사양서로 가면 이월 저장 칸 추가 + 목표 XP(30) 비율 축소 필요.
2. **레벨표:** 사양서 Lv2=30XP … Lv10=630XP(105시간) vs 현재 100×레벨. 시연에서 레벨업을 보이려면 사양서 기준은 너무 느림.
3. **준비 화면에 "오늘의 공부 내용" 입력**을 둘지 (현재는 회고에서만).
4. **회고 3칸(사양서)** vs **4칸(9/21 확정)**.
5. 9/26 적용한 디자인 색이 괜찮은지.

그 외: 나머지 캐릭터 3종의 성장 단계 그림(팀원 1에게 요청), 걷기·상호작용 프레임 사용 여부(선택), `짜투리` 폴더 용도.

1. **Genspark 시험 배포** — 저장소를 가져와 빌드·배포되는지, D1·R2 바인딩이 연결되는지 확인. 배포 후 `wrangler.jsonc`의 `database_id`·버킷 이름을 실제 값으로. 문제 나오면 버전 낮추기(Vite 5/Wrangler 3) 검토.

## 7. 알아두면 좋은 함정

- Windows에서 Python으로 파일을 쓸 때 `/c/Users/...` 경로를 쓰면 `C:\c\...`에 생긴다. `C:\Users\...`로 쓸 것.
- 스키마 변경 후에는 개발 서버를 끄고 `npm run db:reset:local`. 개발 서버가 켜져 있으면 DB 파일이 잠긴다.
- `scripts/api-check.mjs`는 로컬 DB에 `wrangler d1 execute --local`로 시작 시각을 과거로 옮겨 8시간 상한 등을 검사한다(로컬 전용).
- 브라우저 콘솔의 401 오류는 로그인 전 첫 요청 흔적이라 정상.
- 노션 "바로가기"의 GitHub 링크·배포 URL 칸이 아직 비어 있다.
