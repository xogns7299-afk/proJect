# 시연 데이터 (초기 상태로 되돌리기)

- 최종 수정: 2026-09-27
- 파일: `scripts/demo/make-seed.mjs`(만드는 스크립트) → `scripts/demo/seed.sql`(실행할 SQL)
- 한 줄 요약: **`seed.sql`을 실행하면 test1~test4 네 계정이 언제든 같은 초기 상태로 돌아간다.** 리허설로 기록·경험치가 바뀌어도 다시 실행하면 된다.

## 1. 계정별 초기 상태

| 계정 | 역할 | 경험치 · 레벨 | 기록 | 과목 |
|---|---|---|---|---|
| test1 | 발표자, 스터디장 | 998 XP · Lv4 (다음 레벨까지 2 XP) | 9/14~9/26, 20건 | 자료구조 · 토익 · 웹프로그래밍 |
| test2 | 열공러 | 4760 XP · Lv10 (어른 모습) | 9/1~9/26, 47건 | 정보처리기사 · 선형대수 · 영어 · 알고리즘 |
| test3 | 꾸준히 하는 사람 | 1790 XP · Lv6 (성장 모습) | 9/7~9/26, 25건 | 회로이론 · 한국사 · 코딩테스트 |
| test4 | 막 시작한 사람 | 190 XP · Lv2 | 9/22~9/26, 5건 | 파이썬 기초 · 영단어 |

- 공통: 주별 목표(지난 주들 + 9/28 주), 할 일, 개인 일정(9/30 발표, 10월 시험 등)

- 경험치는 서버와 같은 규칙으로 기록·완료한 목표에서 계산해 넣는다 (기록 1분 = 1 XP, 1건 최대 240 / 목표 1개 30 XP)
- **발표 시연:** test1로 타이머를 2분 이상 돌리고 종료하면 Lv5가 되며 성장 모습이 공개된다. 목표를 먼저 체크해도(+30 XP) 레벨이 오르니, 레벨업 장면은 타이머로 보여 준다.

## 2. 실행하면 바뀌는 것 / 안 바뀌는 것

| 바뀜 (지우고 초기 상태로 다시 넣음) | 그대로 |
|---|---|
| 네 계정의 과목, 공부 기록(진행 중 타이머 포함), 경험치, 할 일, 일정, 주간 목표, 표시 모습 설정 | 계정 자체: 아이디, 비밀번호, 닉네임, 고른 캐릭터, 복구 코드 |
| 네 계정이 만든 스터디와 그 멤버·응원·댓글, 네 계정이 남긴 응원·댓글 | 로그인 상태 (다시 로그인할 필요 없음) |
| | **다른 모든 계정과 그 데이터** |

- **안전장치:** test1~test4 중 하나라도 없으면 첫 줄에서 `malformed JSON` 오류로 멈추고 아무것도 바꾸지 않는다.
- 몇 번을 실행해도 결과가 같다 (난수 씨앗 고정).

## 3. 되돌리는 방법

### 배포 사이트 (Genspark)

배포 DB는 Genspark만 실행할 수 있다. 아래 문구를 보낸다. **코드가 바뀌지 않았으면 재배포는 필요 없다.**

```
시연 데이터를 초기 상태로 되돌려 주세요.
1. 먼저 현재 D1 DB를 백업해 주세요 (wrangler d1 export).
2. GitHub 최신 코드를 가져와 주세요 (git fetch 후 git reset --hard origin/main).
3. 배포에 연결된 D1 데이터베이스(마이그레이션을 적용할 때 쓰는 것과 같은 DB)에
   scripts/demo/seed.sql 을 --remote --file 로 실행해 주세요.
4. 마지막 SELECT 결과(계정별 xp, records)를 알려 주세요.
   정상이면 test1 998/20, test2 4760/47, test3 1790/25, test4 190/5 입니다.
5. 재배포는 하지 마세요 (데이터만 바꾸는 작업입니다).
```

### 로컬 (팀장 PC)

로컬 DB에도 test1~test4로 먼저 가입해 두어야 한다.

```bash
npm run demo:reset:local
```

## 4. 초기 데이터를 바꾸고 싶을 때

1. `scripts/demo/make-seed.mjs`의 `USERS`(과목·목표·할 일·일정·목표 경험치 `targetXp`)나 `LAST_DAY`(기록 마지막 날)를 고친다. `seed.sql`은 직접 고치지 않는다.
2. `npm run demo:sql` → `seed.sql`이 다시 만들어진다.
3. `npm run demo:reset:local`로 로컬에서 확인한 뒤 GitHub에 올리고 위 문구로 배포 DB에 반영한다.
